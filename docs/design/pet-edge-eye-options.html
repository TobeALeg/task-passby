WORKET / EDGE RESTING

藏起身体，留下目光。

三种方案均不露嘴巴。上方、侧边与 Dock 两侧保持同一种视觉语言。仅为预览，尚未应用。

OPTION 01

圆弧探头推荐

只留一小段圆头和两只眼睛。保留土豆的柔软感，最容易认出。

  • 露出约 18–20 px
  • 无嘴、无爪；轮廓圆润
  • 轻巧，但不容易找不到
OPTION 02

双爪偷看

两只眼睛搭配边缘上的小爪子，明确表达“扒住”，身体藏在边外。

  • 露出约 16–18 px
  • 无嘴；保留两个小爪尖
  • 性格更鲜明，更像陪伴角色
OPTION 03

极简眼条

只保留极薄的金色边条和两只眼睛。收纳感最强，视觉打扰最少。

  • 露出约 10–12 px
  • 无嘴、无爪；扁平小条
  • 最省空间，角色辨识度稍弱
上方为桌面位置示意，下方为轮廓放大预览。最终点击范围可略大于可见形态，方便拖出。
