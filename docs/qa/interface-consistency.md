# Worket 界面统一验收（2026-09-11）

范围：桌面最近活动、历史聊天、进行中 / 已完成 / 归档列表和详情，交接、分割、取消记录，沉淀范围、任务、候选编辑、定义版本、复用、验收，服务连接、改进数据，桌宠状态气泡；后台登录 / 初始化、模型配置、接入、运行记录、改进样本及详情。

## 设计与审查

- 系统无衬线字体；正文和按钮 13px、辅助信息 12px、标题 20px（后台页面标题 28px）。标准控件 32px，圆角 8px；白灰底色、蓝色主操作、红色破坏性操作。
- 工作列表去除重复的“选择沉淀：标题”，保留有可访问名称的复选框。没有选中工作时禁用批量沉淀。
- 详情独立显示并可返回列表。交接 / 完成 / 沉淀为可见操作，其余进入更多菜单；不为八个空状态字段铺设占位块。
- 更多菜单选择后、点击外部或按 Escape 收起。异步工作操作防重复提交并显示失败；后台轮询避免覆盖弹窗和菜单，数据未改变时不重建工作视图。
- 弹窗由自身限制宽高，内层不再声明超过父级的宽度。全部表单控件统一，定义编辑仅在选项类型显示可选值字段。
- 删除页面功能介绍、重复标题与领域实现术语。授权的实际范围及不可恢复后果以短句展示，详细留存和退出规则按需展开；授权状态与服务端行为不改。
