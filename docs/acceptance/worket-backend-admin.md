## 使用与后续验收

打开后台，设置自己的管理员密码，填写模型基地址、模型名和 API Key，点击“测试连接”后“保存并启用”。在“Worket 接入”生成凭据，填到桌面 App 的“更多 → Worket 服务”。本机 HTTP 连接需要开发模式；完整启动及服务器部署说明见 [server/README.md](../../server/README.md)。

后台已在本机运行，未部署公网或配置开机自启动。真实供应商连通性、沉淀质量与真实 WorkBuddy 第二次执行仍需要用户填写配置和指定授权工作之后验收；本次模拟 Provider 测试不代表这些环节通过。公开产品的注册、登录和账户恢复未包含在私有后台范围内。

## 本机简单密码补充

按用户仅在本机使用的要求，管理员密码下限从 12 位调整为 6 位，前后端校验一致；用户可自行填写简单数字密码，不预设或覆盖已有管理员密码。现有后台 8 组测试使用 6 位数字密码全部通过，包含首次设置、登录、错误密码拒绝及重启恢复；后台已重启使规则生效。
