# Worket 0.1.3

发布日期：2026-09-12。

## Windows x64 首个公开版本

Worket 现可作为 Windows x64 便携应用运行，保留 macOS 版相同的工作对象、桌宠、轻量面板、记录、交接与沉淀模型。

- 增加 Win32 前台窗口与标题识别；Worket 在前台时可向后找到最近的受支持工作窗口。
- 增加 Windows 托盘、应用图标、单实例唤回和任务栏避让。
- 兼容 Windows Codex App Server 路径与环境，并为 WorkBuddy 本机桥使用按用户隔离的命名管道。
- Windows 资料路径、GitHub Release 附件选择、SHA256 下载校验和手动替换提示按平台处理。
- 增加 `package:win`、`release:win` 与跨平台 `npm start` 构建入口。

Windows 包是未签名便携 ZIP，不是安装器。解压后应保留整个 `Worket-win32-x64` 文件夹并运行其中的 `Worket.exe`；Windows SmartScreen 可能提示来源未知。

## 交接展示修正与评测资料

待确认交接使用的占位会话不再提前冒充目标执行者，也不计入用户看到的真实执行片段数量。真实目标会话绑定后才切换执行者展示。

项目补充跨 Agent 交接成本与有效性评测方法，以及公开对话数据的跨模型交接实验设计。这些是评测依据，不代表交接收益已经得到实验证明。

## 验收边界

Windows 打包应用的窗口、界面、单实例恢复和合成更新链已经验证；从本地固定安装位置进行的 Codex 会话选择与真实历史导入也已通过。Windows Codex 主窗口只提供通用 `ChatGPT` 标题时会要求用户选择会话。Windows WorkBuddy、双向交接、DPAPI、高 DPI、多屏与休眠恢复仍需在普通用户桌面会话中持续验收。

安装包：`Worket-0.1.3-win32-x64.zip`，并提供同名 `.sha256` 校验文件。
