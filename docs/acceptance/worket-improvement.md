## 可验收行为

| 场景 | 结果与证据 |
|---|---|
| 后台查看样本与来源 | “改进样本”展示授权、期限、所选材料、来源映射与事件链；浏览器实际展开来源文本，包含 HTML 标记的材料按普通文本显示 |
| 后台评审与删除 | 备注和待评审/已评审状态在刷新后保留；删除提供确认/保留，确认后正文、反馈和备注一起移除 |
| 接收开关 | 暂停/恢复通过；暂停不能撤销既有授权，也不增加模型调用 |
| 独立授权 | 沉淀和复用均默认不勾选；旧版处理授权不留改进正文；新工作输入不沿用旧授权 |
| 自动反馈 | 固定来源、候选原稿、用户修改、发布、复用和逐项验收形成独立事件；修订记录可在进程重启后补齐 |
| 网络与隔离 | 离线队列持久化；重传去重、内容冲突拒绝；改变服务/凭据暂停同步；客户端不能读取他人样本，删除仅作用于认证主体 |
| 停止与删除 | 客户端停止单个/全部样本，清空待发正文；离线删除保留待确认状态，恢复原服务后完成；后台删除标记阻止迟到上传恢复 |
| 到期与限额 | 90 天从授权起算，反馈不续期；过期清理通过；事件过大暂停采集并显示错误，不破坏本地编辑或发布 |
| 桌面实际运行 | 最终打包应用在隔离用户目录跑通授权→沉淀→编辑→发布→新范围授权→复用→用户验收→重启→停止→删除 |

## 实际边界

单次范围授权，不是全库扫描或持续桌面监控。沉淀仅固定快照及明确选中的附件文本，排除 reasoning.summary；复用只记录定义版本、非文件输入、验收和选中交付 ID，不读取新工作对话或交付正文。采集本身不触发额外模型请求；正常“开始沉淀”仍会按用户既有模型配置调用供应商。

样本保存于后台独立 `improvement.sqlite`，不进入 Git、桌面包或运行日志；用户本地工作与正式定义独立保留。尚无导出到独立评测正文副本的功能，评审备注随样本删除。到期清理需服务运行，停机期间在下次启动清理。停止可能无法追回已发出的请求，删除用于完整移除已留存样本。

凭据改变会暂停待同步数据；原凭据到期或无法恢复时，后台管理员仍能删除。首版不支持把已停止样本重新启用，新的范围需重新明确授权。真实样本构造评测及跨版本效果比较属于后续工作，不在本次验收结果中。
