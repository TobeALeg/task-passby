# 工作沉淀 v1 开发验收记录

日期：2026-09-08。依据：`docs/specs/work-distillation-v1.md`。结论：**开发闭环已实现，自动化与合成桌面验证通过；真实功能和公开分发验收未通过，不能对外宣称 P0 已完成。**

## 已实现范围

- SQLite `user_version=2` 显式迁移，迁移前 `VACUUM INTO` 备份；现有定义扩展 GENERAL/REUSABLE，不迁移 ARCHIVED 为定义。
- 本地固定来源快照、手动授权提交、远端异步任务、草稿并发编辑、问题处理、独立用户编辑/确认记录、固定版本发布及命令幂等。
- 独立 Worket AI HTTP 服务；有签名/主体/受众/期限校验的开发身份和 RS256 生产验证入口；主体隔离、调用限额预占、内存结果、ack/取消清理、元数据持久化及重启中断语义。
- 固定分块提取与聚合流程，无模型工具；输出结构、事件覆盖、引用越界、来源角色、模板变量校验。模型 Provider 仅存在于 `server/`，打包排除此目录。
- 选择来源、逐项候选编辑、来源核验、固定资料副本、已沉淀列表、版本查看/修订、新输入、可选旧参考案例。
- 新实例先落盘、无虚假绑定；START/CONTINUE 工作包、Markdown/JSON 出口；WorkBuddy 启动幂等、真实 Hook 绑定及 MCP 读取证据；逐项用户验收与本次交付关联。
- 删除来源清理快照正文/附件分析内容/证据摘录、失效未保存草稿并排队取消远端；已确认定义保留。定义仍被实例引用时拒绝删除。

## 实测证据

1. `npm test`：85/85 通过，包含原有回归及新增的事务、服务和执行端契约测试。服务契约测试在本机临时端口使用合成模型，初次沙箱禁止监听，获准本机测试后通过。
2. `npm run typecheck`、`git diff --check` 通过。
3. `npm run package:mac` 生成 `release/Worket-darwin-arm64/Worket.app`。首次沙箱无法解析 GitHub，允许打包所需下载后成功。
4. `node scripts/qa-distillation.mjs`：实际打包 Electron 应用、实际 preload/IPC/SQLite、实际本地 HTTP 服务，使用合成来源和测试 Provider。确认前调用数 0；完整候选生成调用数 2；新实例不含旧客户；人工验收 UI 完成后重启，定义和完成状态恢复；448px 面板无水平溢出。
5. 截图与机器报告位于 `output/distillation/01-confirm-range.png` 至 `06-restarted-definitions.png`、`desktop-report.json`。这些是开发测试材料，没有外发用户真实工作库。
6. `npm run qa:package`：通过，Dock 可见、二次启动恢复窗口、桌宠状态和面板回归通过。
7. `node server/evaluate.mjs`：明确返回 `BLOCKED`、8 类固定样例、真实模型调用数 0。`output/distillation/model-evaluation.json` 记录缺配置，不能把它统计为质量通过。

## 当前阻塞及限制

- 未配置服务端模型供应商、模型、Key 安全路径，无法执行真实质量集。质量案例需人工核对关键要求、禁止泛化项、旧客户污染和引用；脚本不自动宣称质量通过。
- 身份服务、正式登录体验、HTTPS 部署、准确的供应商数据政策和商业额度尚未落定。客户端当前“Worket 服务”入口接收开发联调访问令牌并用 Electron safeStorage 加密；这不是最终新用户登录体验。生产服务拒绝开发签名，但仅此不足以公开上线。
- 尚未指定允许外发的真实工作与不同的新输入。不能擅自选择已有私有记录提交模型，也不能使用测试交付物冒充真实第二次工作。
- 新应用拒绝更高版本的数据库；迁移将真实采集绑定存储移到 capture_bindings_v2，旧 capture_bindings 名称保留只读升级屏障，基线旧二进制初始化被阻止。回滚必须停止应用并恢复迁移前备份，不承诺旧版直接读新库。用户永久删除记录时会同步移除含旧正文的迁移备份；此后该备份不能用于回滚。
- 未做公开发布、上传 Release 或部署后台。当前打包产物仅供本次开发审查和联调。
