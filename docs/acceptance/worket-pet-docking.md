# 桌宠贴边收纳验收

2026-09-11。用户目标：减少桌宠占用，拖至桌面左、右、上边缘时切换为扒边形态。

## 实现与边界

- 拖动松手时在显示器可用区域边缘 24 像素内吸附，进入菜单栏或侧边 Dock 所占区域也能触发；最终位置在可用区域内，底部不吸附。
- 左右窗口 32×68，顶部 68×32，实际收小原生窗口；保留小头、双爪和状态点，隐藏气泡与便利贴。单击继续打开面板，拖离恢复 304×270 正常窗口。
- 正常位置沿用原 `{x,y}` 偏好，贴边时保存 `edge`；重启恢复贴边状态，显示器移除与分辨率变化回到可见工作区。没有修改工作采集或上传生命周期。
- 当前吸附对象是桌面可用区域边缘，不跟踪其他应用窗口的边框。此次没有打包或发布桌面版本。

## 验证

`npm test`：112/112 通过。新增几何测试覆盖三边、底部不吸附、阈值与角落、菜单栏/侧边 Dock、负坐标显示器、正常大小恢复、旧配置兼容。

`node scripts/qa-pet-drag.mjs --unpackaged`：隔离临时数据目录的真实 Electron 开发实例通过。原生窗口位移、拖动不打开面板、单击打开、正常重启位置、三种紧凑窗口尺寸、贴边单击不脱离、贴边重启恢复、原生 pointer capture 拖出恢复、显示器移除后的贴边找回、窗口销毁后的激活安全均通过。三边放置使用真实 preload IPC 和原生窗口，脱离与点击使用 Playwright pointer 事件；不是人工手拖或最终安装包验收。
